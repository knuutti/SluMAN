SluMAN v1.1.6

New game

  • Bentley's Hackpack (NPEA00427, PAL PSN) is now supported, running on the Sly 4 code.
  • Practice Mode: start and restart jobs (each minigame stage), warp to challenges, load the hub, Slow Motion and Auto-skip Cutscenes, plus Sly 4's Jobs, Camera and Tunables tabs. Levels are named from the game's own level list.
  • Speedrun Mode: input display and an autosplitter (autosplitters/hackpack-autosplitter.asl, not properly configured yet).

New features

  • Uniform Practice Mode: every game's Practice window now has the same layout, with shared features in the same place and under the same name.
  • Practice tab: Level / Map, Job, Reload and Saved Positions on the left; Game status, Utility and Toggles on the right. Toggles are in the same order in every game, with Always On Top last.
  • Tabs in the same order everywhere: Practice, Player, Camera, the game's own tabs, then Memory and Memory Viewer.
  • Shared Tools menu in every game (Sly 4 gains Controller Combos).
  • Fly Mode is R1 up / L1 down in every game, with R2 boost.
  • Features a game doesn't have yet are shown as disabled placeholders.
  • Sly 1 Practice Mode: added a Camera tab with a free camera, camera paths, Hide HUD and No Fog. Sly's controls are taken away while the free camera flies.
  • Sly 1 Practice Mode: added a Powerups tab for editing unlocked vault powerups, Mz. Ruby's Invisibility, world blueprints and the equipped powerup.
  • Sly 4 Practice Mode: added a Gadgets tab with a checklist per character. Changes are applied with a checkpoint or level reload, and each run file's gadgets can be saved.
  • Sly 4 Practice Mode: added a Run Files tab (Episodes 1–5) that goes to the episode's first hideout and sets the gadgets saved for it.
  • Sly 4 Practice Mode: the Player tab now uses the shared position editor, adding axis freezes, warp locations and the saved position slot grid. Fly Mode is now a Practice toggle.
  • Sly 4 Practice Mode: added a Freeze Game Clock toggle.
  • Sly 4 Practice Mode: the free camera now works in the hacking minigames (System Cracker, Spark Runner, Alter Ego). It holds the game's time nearly still there and turns off the depth of field blur.
  • Sly 4 / Hackpack Tunables tab: added Reset to Defaults. The original values are also restored when Practice Mode closes and when Speedrun Mode opens.
  • Sly 4 / Hackpack Tunables tab: added an "Only this level" checkbox that hides tunables in deeper categories.
  • Sly 2 and Sly 3: saved positions and warp locations now also save which way the player is facing.
  • Sly 2 Practice Mode: the Player tab now shows character ID, health, gadget power, opacity and velocity.
  • Sly 2 Practice Mode: added Discard Changes to the Gadgets tab.
  • Sly 2 and Sly 3 Practice Mode: added a Game status group (map, coins, health) and Saved Positions on the Practice tab.
  • Character Info has a Top Speed row with Reset in every game.
  • Camera Script API: a local HTTP API (127.0.0.1:9675) that lets scripts move the free camera, set the field of view and far distance, and toggle Hide HUD, No Fog and Freeze Game Clock. Works in every supported game, turned on from the Camera tab. See .claude/camera-api.md.

Changes

  • Sly 4: warping to a checkpoint now always restarts the running job at that goal. The Reload Job on Warp checkbox has been removed.
  • Sly 2 / Sly 3: Skip Cinematic moved to the Reload group.
  • Sly 4: Coins moved from the Player tab to the Practice tab's Utility group.
  • Saving a run file's gadgets leaves out the gadgets that aren't available yet in that episode, with a warning naming them.

Bug fixes

  • Sly 2 and Sly 3: warping through a death plane no longer kills the player when the destination is safe.
  • Sly 4: the free camera no longer crashes the game when it sees more than the game's own cameras do (e.g. looking over a whole hacking level).
  • Sly 4: the free camera now turns and moves the right way in Spark Runner, and the level no longer goes dark there.
  • Sly 2: Kill with "Default" no longer switches to Sly first.
  • Sly 3: toggle errors no longer throw out of their handlers. Sly 2 and Sly 3 toggle errors now show in the status line.
  • Sly 2 and Sly 3: field of view changes in the free camera apply immediately instead of easing in.
