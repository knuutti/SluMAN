SluMAN v1.1.1

New features

  • Sly 3 maps can be loaded at any job checkpoint's spawn point: 248 spawn points across 38 maps.
  • Sly 2 and Sly 3 Practice Mode remember every spawn point a load arrives at and list it in the map's Spawn point dropdown.
  • Sly 1 and Sly 4 Practice Mode show the "SluMAN (Practice Mode)" popup on the PS3 after loads, like Sly 2 and Sly 3.

SluMAN v1.1.0

New features

  • Sly Cooper: Thieves in Time support, in Practice Mode and Speedrun Mode (BCES01284 disc and NPEA00429 PSN).
  • Sly 4 Practice Mode:
  • Invulnerable, Undetectable, Slow Motion and Skip Cutscenes toggles.
  • Shows the current episode, job and checkpoint.
  • Start Job, To Hub, To Hideout, Warp to Goal and Retry.
  • Saved positions.
  • Sly 4 tabs:
  • Tunables: all of the game's ~2,650 tunables, live, searchable and editable. Keep values you change, or import a SLY4-DEBUG-MENU debugmenu.cfg.
  • Jobs: every episode, job and goal, with the running job's progress.
  • Position: teleport, a speedometer, Fly Mode and a freecam.
  • Sly 4 Load Level: any level, as any character, at any of ~3,000 named spawn points.
  • Sly 1 Practice Mode:
  • Load any level at its start or any entrance.
  • Reload Level and Skip Cinematic.
  • Set coins, lives and charms.
  • Freeze Lives, Freeze Gold Charm, Fly Mode and Infinite Jump.
  • A Player tab with position slots and warps.
  • A World States tab for each world's keys, vaults, sprints and progress.
  • Sly 2 PAL PSN (NPEA00342) is supported.
  • Language menu for PAL Sly 2 and Sly 3 (Tools → Language).
  • Sly 2 and Sly 3 Practice Mode reworked like Sly 4's:
  • One window with Practice, Player, Gadgets, Run Files, Memory and Memory Viewer tabs.
  • A View menu to pick which tabs show.
  • Run files now load from Practice Mode's Run Files tab. Speedrun Mode has only the autosplitter, Always On Top and the input display.
  • Sly 2 and Sly 3 jobs load by job and checkpoint, and maps load at a chosen spawn point.
  • Sly 2: Tools → Copy Episode State, for recording job states.
  • Memory Viewer: Ctrl+C copies the bytes on screen.
  • Sly 1 autosplitter removes loads from Game Time (Real Time is unchanged).

Bugfixes

  • Sly 2 autosplitter:
  • Any% now splits jobs in every episode, not just Episode 1.
  • A job no longer splits twice, and split timing is more reliable.
  • Sly 1 autosplitter no longer misses the Hideout split after a boss.
  • Sly 3 Fly Mode no longer crashes the game in and around hideouts.
  • Auto-skip Cinematics now skips FMVs in Sly 2 and Sly 3.
  • Sly 3 Skip Cinematic and Auto-skip handle dialogue better.
  • Practice windows fit each tab instead of leaving empty space at the bottom.
  • The Controller Combos, Autosplitter, Memory and Mod Loader windows now show the SluMAN icon.

Maintenance

  • Removed the Run Script controller combo; it did nothing in supported games.
  • Sly 1 Speedrun Mode is rebuilt like the other games'.
  • Sly 4 support builds on SLY4-DEBUG-MENU by gg3502, and Sly 1 Practice Mode uses addresses from SlyMultiTrainer by NiV-L-A. Thank you!

SluMAN v1.0.10

New features

  • Practice Mode is now one window with tabs: gadgets, Position Editor, Memory Utilities and a new Memory Viewer (live hex view you can edit).
  • Controller combos in Practice Mode for Save/Load Position, Load Game and Run Script (Tools → Controller Combos).
  • Named position slots: 8 per map in the Position Editor.
  • Auto-skip Cinematics toggle for Sly 2 and Sly 3.
  • Sly 3: Freeze Game Clock, Disable Death Barriers, Disable Guard AI, Invulnerability, Infinite Jump and Fly Mode toggles, and warp locations per map, including your own.
  • Sly 2: Invulnerability, Infinite Health, Infinite Gadget Power, Infinite Jump and Freeze Game Clock toggles, and the Position Editor.
  • Gadgets tab can load gadgets from a run file.
  • Memory watches support pointer chains and calculated functions (e.g. a speedometer), and watchlists save automatically.
  • Input display can be added to OBS as a Browser Source: http://127.0.0.1:9674/pad.
  • Starting a different Sly game opens it in SluMAN without re-attaching.
  • Messages show in a status line instead of popups, and updates show as a link next to the version.
  • Sly 2 NTSC-U (NPUA80664) can be attached (untested).

Bugfixes

  • Saved positions load again, and are now kept per map.
  • Attaching no longer freezes the window on a wrong IP, and SluMAN recovers when the PS3 stops answering.
  • Input display and autosplitter keep working after game resets and game switches.
  • Sly 2 Infinite Jump works, and Set Health sets Bentley's health.
  • Toggles are applied again after every load.
  • Fixed high CPU use with light input display skins.
  • Detects when Windows Firewall blocks live data and offers to add a rule.
  • Closing the Sly 3 Practice window no longer closes the whole app.

Maintenance

  • Settings and saved data are now kept in %APPDATA%\SluMAN and copied there from the SluMAN folder on first start.
  • The autosplitter memory file is renamed, so the old .asl scripts no longer work. Point LiveSplit's Scriptable Auto Splitter at the .asl in this version's autosplitters folder, or copy it again if you keep a copy in the LiveSplit folder.
  • Removed Sly 2 PAL support (its addresses were wrong) and the leftover Ratchet & Clank mods.
  • Releases are now built and published automatically.
