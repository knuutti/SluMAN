# Sly 3 spawn points: map | spawn ID | English name
#
# The Map group in Practice Mode lists a map's spawn points from this file, after the map's own
# start. The map is its internal name without "Y$KF"; the spawn ID is the value at the spawn
# location address after going through a door. Write the English name after the second |; a
# spawn point without one shows as its ID. Everything after a # is a comment: here, where the ID
# came from (a run file or the map's start), to help name it.
#
# Sly 3's job list loads jobs without a spawn ID (the game places the player at the checkpoint),
# so these were gathered by loading every job checkpoint and noting where each load arrived
# ("job checkpoint"), plus the map list, the run files and the address sheet's "Sly 3 Reload
# Spawn Locations". Practice Mode also remembers every spawn point a load arrives at, in
# s3_seen_spawn_points.txt in the user data folder; copy new ones here to ship and name them.
